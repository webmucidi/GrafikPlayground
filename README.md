# Photoshop Seçim ve Silgi Araçları Antrenmanı

Photoshop'ta senaryoya uygun aracı seçmeyi pekiştiren, animasyonlu soru-cevap uygulaması.

- **Lasso araçları:** Lasso, Polygonal Lasso, Magnetic Lasso (11 senaryo)
- **Silgi araçları:** Eraser, Magic Eraser, Background Eraser (11 senaryo)

Her cevaptan sonra doğru aracın kullanımı animasyonla gösterilir ve gerekçesi açıklanır.

## Çalıştırma

Tek dosyalık, bağımlılıksız statik bir sayfadır: `index.html` dosyasını tarayıcıda açmanız yeterlidir.

## Yayınlama

GitHub Pages, Netlify, Vercel veya Cloudflare Pages gibi herhangi bir statik barındırmada kök dizinden (`/`) yayınlanabilir. Build komutu gerekmez.
